# Investment Strategy Analyzer 
An AI-powered investment analysis platform that helps investors evaluate portfolio performance, analyze market trends, and generate actionable insights.

## Features
- Portfolio performance tracking
- Historical stock analysis
- Risk and return metrics
- Automated market data collection
- AI-assisted investment reporting

## Tech Stack
- Python
- Pandas
- NumPy
- yFinance
- SQL
- Git
